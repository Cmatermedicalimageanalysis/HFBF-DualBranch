        <h1>
            A Hierarchical Factorized Bilinear Fusion based Dual-branch Deep Learning Model 
            for Histopathology Image Classification
        </h1>

        <p>
            This is the official GitHub repository corresponding to the research paper entitled 
            <strong>
                A Hierarchical Factorized Bilinear Fusion based Dual-branch Deep Learning Model 
                for Histopathology Image Classification
            </strong>. 
            The research work is conducted by the authors from the 
            <b><em>Department of Computer Science and Engineering, Jadavpur University, India</em></b>.
        </p>

        <p>
            The proposed framework introduces a dual-branch CNN architecture using 
            <b>EfficientNet-B0</b> and <b>MobileNetV3-Large</b> to extract complementary multi-scale 
            feature representations from histopathological images. A novel 
            <b>Hierarchical Factorized Bilinear Fusion (HFBF)</b> module is employed to model 
            higher-order cross-branch feature interactions. The fused representations are further 
            enhanced using <b>Squeeze-and-Excitation (SE) attention</b> for discriminative 
            channel-wise feature recalibration, followed by a regularized fully-connected classifier 
            for breast cancer classification.
        </p>
